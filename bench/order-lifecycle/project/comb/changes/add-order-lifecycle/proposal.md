# Change: Order lifecycle for the Kurumi MVP

## Why
Buyers and sellers need a safe path from "Buy" to completion, cancellation or refund, with Kurumi holding the money until the transaction completes.

## What Changes
- Adds the order-lifecycle capability: payment, shipment, delivery, confirmation, auto-completion, cancellation, disputes, returns, refunds, chargebacks, admin force-cancel and seller payout.

## Impact
- Capabilities: order-lifecycle (new)
- Requirements: REQ-ORDER-001..REQ-ORDER-018 (new)
