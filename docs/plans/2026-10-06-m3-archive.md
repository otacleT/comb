# M3 Archive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the loop: a clarified change is merged into the canonical specs and decision log deterministically, and the next change on the same capability is reviewed against what was decided before (V0_SCOPE experiences E5 and E6).

**Architecture:**
- `comb validate --change` records the canonical hash of every MODIFIED or REMOVED target in `.comb.yaml` `base` once, and every check reports `BASE_DRIFT` when the spec moved since then (S1).
- `src/core/change/apply-delta.ts` applies one delta to one canonical spec by replacing text ranges, so bytes outside the touched blocks stay as they were. Each operation is skipped when its result is already there.
- `src/core/decision/permanent.ts` gives change-local decisions permanent `D-NNN` ids, rewrites the references, and appends the decisions to `comb/decisions.md` with `Change:` and `Superseded by:`.
- `src/core/change/archive-plan.ts` (pure) checks the gates, composes every write, and re-validates the merged result. `archive-execute.ts` writes temp files, moves the change folder, then renames the temps into place.
- `comb list` / `comb show` expose specs, decisions and changes by id. `comb instructions apply` and the `apply` / `archive` skills complete the workflow set.

**Tech Stack:** Node ≥22.12, TypeScript 7 (strict, NodeNext, `"types": ["node"]`), commander 15, yaml 2 (`parseDocument` for frontmatter edits), mdast-util-from-markdown, mdast-util-to-string, vitest 5.

**Spec:** `docs/DESIGN.md` (§3.1, §3.2, §3.7, §3.8, §4, §5.1, §5.3, §7, §8), `docs/V0_SCOPE.md` (M4, M9, M10, M12, S1, E5, E6), `docs/IMPLEMENTATION_PLAN.md` (M3 table), `docs/DECISIONS.md` (D-012, D-019)

## Global Constraints

- Everything in the M1 and M2 plans' Global Constraints still applies.
- Only `comb archive` writes the canonical files (`comb/specs/**`, `comb/decisions.md`). `comb validate --change <id>` is the only other writer, and it writes nothing but `.comb.yaml` `base` (DESIGN §3.8: record once, never overwrite).
- Permanent decision ids are `D-` plus the number zero-padded to three digits (`D-001`, `D-022`, `D-1000`), continuing after the highest number in `comb/decisions.md`. Local ids get numbers in their own numeric order (`D-1` before `D-2`).
- Local ids are rewritten as whole tokens (`/\bD-\d+\b/`, exact-string lookup) in the delta(s), `questions.md` and `decisions.md` only. Ids not in the map (`D-021`, `D-10` when only `D-1` is local) are left alone.
- Archive is all or nothing. Any validation error, gate, id conflict or post-merge validation error means nothing is written. The change folder moves before the canonical files are replaced, so a failed move leaves the canonical files untouched.
- Text is processed LF-normalized. When an existing file is overwritten, its BOM and CRLF line endings are restored.
- The archive folder is `comb/changes/archive/<today>-<id>/`, where `today` comes from `CliContext.today` (injectable in tests).
- New diagnostic codes, all added to DESIGN §7.2:
  - `ARCHIVE_BLOCKED` (1), `ARCHIVE_TARGET_EXISTS` (1), `DECISION_ID_CONFLICT` (1), `ID_NOT_FOUND` (2)
  - `BASE_DRIFT` (warning) is emitted for the first time.
- Rulings made in this plan, which the spec leaves open:
  - Archiving a change with no `review.md` needs `--yes`, like unfinished tasks. A stale review always blocks.
  - Re-running a completed archive is a no-op (`CHANGE_NOT_FOUND`, exit 2). `applyDelta` skips operations that are already applied (DESIGN §5.3.8), but archive does not try to resume an interrupted run: the canonical files are in git, and the validation errors show what happened.
  - A delta's `## Purpose` replaces the Purpose section of an existing capability. A delta Section may not be named `Requirements` or `Purpose`.
- Work on branch `feat/m3-archive`. This plan is that branch's first commit.

## Review Focus

1. **An existing spec saved with a BOM and CRLF line endings** (a Windows editor) must keep both after archive, and only the touched block may change. Pinned in Task 5 ("keeps the BOM and CRLF line endings of an existing spec").
2. **A hand-written `D-1` in `comb/decisions.md` that collides with the change's local `D-1`**: references would become ambiguous, so archive must stop with `DECISION_ID_CONFLICT` and write nothing. Pinned in Task 3 and Task 4.
3. **A requirement-like heading inside a fenced code block** (`### Requirement: REQ-ORDER-999` in ```` ``` ````) is never a target. REMOVED on it gives `DELTA_TARGET_MISSING` and leaves the text byte-identical, and `comb show` does not find it. Pinned in Task 2 and Task 6.
4. **A delta Section named `Requirements`** would plant a second `## Requirements` heading and hide every existing requirement from the parser. It must be an error, not silent loss. Pinned in Task 2.
5. **Reference rewriting near other ids**: with only `D-1` and `D-12` local, `D-10`, `D-021` and `AD-1` must stay untouched. Pinned in Task 3.

```ts
import { writeFileSync } from 'node:fs';
import { stringify } from 'yaml';
import { diag, type Diagnostic } from '../diagnostics.js';
import type { ChangeMeta, ChangeSnapshot, Project } from '../project/load.js';
import { paths } from '../project/paths.js';
import { blockHash } from '../workflow/hash.js';

interface BaseTarget {
  id: string;
  hash: string;
  file: string;
  line: number;
}

/** MODIFIED and REMOVED targets that exist in the canonical spec, with their current hashes. */
function baseTargets(project: Project, change: ChangeSnapshot): BaseTarget[] {
  return change.deltas.flatMap((d) => {
    const requirements = project.specs.get(d.capability)?.capability.requirements ?? [];
    const targets = [...d.delta.modified.map((r) => ({ id: r.id, line: r.line })), ...d.delta.removed.map((x) => ({ id: x.id, line: x.line }))];
    return targets.flatMap((t) => {
      const current = requirements.find((r) => r.id === t.id);
      return current ? [{ id: t.id, hash: blockHash(current.block), file: d.file, line: t.line }] : [];
    });
  });
}

/** BASE_DRIFT for each recorded target whose canonical block changed after it was recorded (S1). */
export function baseDrift(project: Project, change: ChangeSnapshot): Diagnostic[] {
  const recorded = change.meta?.base ?? {};
  return baseTargets(project, change)
    .filter((t) => recorded[t.id] !== undefined && recorded[t.id] !== t.hash)
    .map((t) =>
      diag('warning', 'BASE_DRIFT', `${t.id} changed in the spec after this change was proposed`, { file: t.file, line: t.line, id: t.id },
        'Update the delta to the current spec; archive then needs --allow-base-drift'),
    );
}

/** Targets that `.comb.yaml` does not record yet. Recorded hashes are never overwritten. */
export function unrecordedBase(project: Project, change: ChangeSnapshot): Record<string, string> {
  const recorded = change.meta?.base ?? {};
  return Object.fromEntries(baseTargets(project, change).filter((t) => recorded[t.id] === undefined).map((t) => [t.id, t.hash]));
}

/** Writes the unrecorded targets into `.comb.yaml` and returns their ids. */
export function recordBase(project: Project, change: ChangeSnapshot): string[] {
  if (!change.meta) return [];
  const add = unrecordedBase(project, change);
  const ids = Object.keys(add);
  if (ids.length === 0) return [];
  const meta: ChangeMeta = { ...change.meta, base: { ...change.meta.base, ...add } };
  writeFileSync(paths.changeMeta(project.root, change.id), stringify(meta));
  return ids;
}
```

```ts
export interface ApplyResult {
  text: string;
  /** Requirement ids and "Section: <heading>" keys whose change was already in the spec. */
  skipped: string[];
  diagnostics: Diagnostic[];
}

export const sectionKey = (heading: string): string => `Section: ${heading}`;

/** Section names with a structural meaning; a delta Section must not use them. */
const RESERVED_SECTIONS = new Set(['Requirements', 'Purpose']);

/** Replaces text[start, end) with `insert` (deletes it when empty), leaving one blank line before what follows. */
function splice(text: string, start: number, end: number, insert: string): string {
  const rest = text.slice(end);
  if (insert === '') return text.slice(0, start) + rest;
  return `${text.slice(0, start)}${insert}\n${rest === '' ? '' : '\n'}${rest}`;
}

/** Adds `insert` as a new block at offset `at`, with one blank line on each side. */
function appendAt(text: string, at: number, insert: string): string {
  const rest = text.slice(at);
  return `${text.slice(0, at).replace(/\n*$/, '')}\n\n${insert}\n${rest === '' ? '' : '\n'}${rest}`;
}

const topBlocks = (text: string): HeadingBlock[] =>
  headingBlocks(text, splitFrontmatter(text).bodyOffset).filter((b) => b.depth === 2);

/** Adds ids to the frontmatter `retired` list, keeping the other keys and their comments. */
export function withRetired(text: string, ids: string[]): string {
  if (ids.length === 0) return text;
  const fm = splitFrontmatter(text);
  if (fm.bodyOffset === 0) return `---\nretired: [ ${ids.join(', ')} ]\n---\n${text}`;
  const doc = parseDocument(text.slice(4, text.lastIndexOf('---', fm.bodyOffset - 1)));
  const data = (doc.toJS() ?? {}) as Record<string, unknown>;
  const list = Array.isArray(data.retired) ? data.retired.filter((x): x is string => typeof x === 'string') : [];
  for (const id of ids) if (!list.includes(id)) list.push(id);
  const node = doc.createNode(list);
  if (isSeq(node)) node.flow = true;
  doc.set('retired', node);
  return `---\n${doc.toString()}---\n${text.slice(fm.bodyOffset)}`;
}

function newCapabilityText(delta: Delta, sections: Section[]): string {
  const blocks = [
    `---\nprefix: ${delta.prefix ?? ''}\n---\n# ${delta.capability}`,
    `## Purpose\n${(delta.purpose ?? '').trim()}`,
    ...sections.map((s) => `## ${s.heading}\n${s.content}`),
    ['## Requirements', ...delta.added.map((r) => r.block.trim())].join('\n\n'),
  ];
  return `${blocks.join('\n\n')}\n`;
}

/**
 * Applies one delta to one canonical spec by replacing text ranges (DESIGN §5.3), in the order
 * REMOVED → MODIFIED → ADDED → Purpose → MODIFIED Sections → ADDED Sections. Text outside the touched
 * blocks keeps its bytes. An operation whose result is already present is skipped.
 */
export function applyDelta(baseText: string | null, delta: Delta, file: string): ApplyResult {
  const diagnostics: Diagnostic[] = [];
  const skipped: string[] = [];
  const fail = (code: string, message: string, id: string): void => {
    diagnostics.push(diag('error', code, message, { file, id }));
  };
  const usable = (list: Section[]): Section[] =>
    list.filter((s) => {
      if (!RESERVED_SECTIONS.has(s.heading)) return true;
      fail('SPEC_PARSE', `a delta section cannot be named "${s.heading}"`, sectionKey(s.heading));
      return false;
    });
  const addedSections = usable(delta.addedSections);
  const modifiedSections = usable(delta.modifiedSections);

  if (baseText === null) {
    for (const r of delta.modified) fail('DELTA_TARGET_MISSING', `${r.id} is not in the spec`, r.id);
    for (const x of delta.removed) fail('DELTA_TARGET_MISSING', `${x.id} is not in the spec`, x.id);
    for (const s of modifiedSections) fail('DELTA_TARGET_MISSING', `section "${s.heading}" is not in the spec`, sectionKey(s.heading));
    return { text: newCapabilityText(delta, addedSections), skipped, diagnostics };
  }

  let text = baseText;
  const spec = (): Capability => parseSpec(text, delta.capability, file).capability;

  const retired: string[] = [];
  for (const x of delta.removed) {
    const cap = spec();
    const r = cap.requirements.find((q) => q.id === x.id);
    if (r) {
      text = splice(text, r.start, r.end, '');
      retired.push(x.id);
    } else if (cap.retired.includes(x.id)) skipped.push(x.id);
    else fail('DELTA_TARGET_MISSING', `${x.id} is not in the spec`, x.id);
  }
  text = withRetired(text, retired);

  for (const m of delta.modified) {
    const r = spec().requirements.find((q) => q.id === m.id);
    if (!r) fail('DELTA_TARGET_MISSING', `${m.id} is not in the spec`, m.id);
    else if (r.block.trim() === m.block.trim()) skipped.push(m.id);
    else text = splice(text, r.start, r.end, m.block.trim());
  }

  for (const a of delta.added) {
    const r = spec().requirements.find((q) => q.id === a.id);
    if (r) {
      if (r.block.trim() === a.block.trim()) skipped.push(a.id);
      else fail('DELTA_ID_EXISTS', `${a.id} already exists with different text`, a.id);
      continue;
    }
    const requirements = topBlocks(text).find((b) => b.text === 'Requirements');
    text = requirements ? appendAt(text, requirements.end, a.block.trim()) : appendAt(text, text.length, `## Requirements\n\n${a.block.trim()}`);
  }

  const setSection = (heading: string, content: string, mode: 'modify' | 'add' | 'upsert'): void => {
    const current = spec().sections.find((s) => s.heading === heading);
    const block = `## ${heading}\n${content.trim()}`;
    if (current) {
      if (current.content === content.trim()) skipped.push(sectionKey(heading));
      else if (mode === 'add') fail('DELTA_ID_EXISTS', `section "${heading}" already exists with different text`, sectionKey(heading));
      else text = splice(text, current.start, current.end, block);
      return;
    }
    if (mode === 'modify') {
      fail('DELTA_TARGET_MISSING', `section "${heading}" is not in the spec`, sectionKey(heading));
      return;
    }
    const tops = topBlocks(text);
    const anchor = heading === 'Purpose' ? tops[0] : tops.find((b) => b.text === 'Requirements');
    text = anchor ? splice(text, anchor.start, anchor.start, block) : appendAt(text, text.length, block);
  };
  if (delta.purpose !== null) setSection('Purpose', delta.purpose, 'upsert');
  for (const s of modifiedSections) setSection(s.heading, s.content, 'modify');
  for (const s of addedSections) setSection(s.heading, s.content, 'add');

  return { text: text.replace(/\n*$/, '\n'), skipped, diagnostics };
}
```

```ts
import { diag, type Diagnostic } from '../diagnostics.js';
import { headingBlocks, type HeadingBlock } from '../markdown/blocks.js';
import type { Decision } from './model.js';
import { parseDecisions } from './parse.js';

const CANONICAL_FILE = 'comb/decisions.md';
const FIELD_LINE = /^\s*[-*]\s+\*\*[A-Za-z][A-Za-z ]*(?::\*\*|\*\*\s*:)/;

const idNumber = (id: string): number => Number(/^D-(\d+)$/.exec(id)?.[1] ?? 0);
export const formatPermanentId = (n: number): string => `D-${String(n).padStart(3, '0')}`;

/** Local D-n → canonical D-NNN, continuing after the highest canonical number (DESIGN §5.3 step 2). */
export function assignPermanentIds(local: Decision[], canonical: Decision[]): { map: Record<string, string>; diagnostics: Diagnostic[] } {
  const canonicalIds = new Set(canonical.map((d) => d.id));
  const clashes = local.filter((d) => canonicalIds.has(d.id));
  if (clashes.length > 0) {
    return {
      map: {},
      diagnostics: clashes.map((d) =>
        diag('error', 'DECISION_ID_CONFLICT', `${d.id} is both a local decision and a decision in ${CANONICAL_FILE}, so its references are ambiguous`,
          { file: CANONICAL_FILE, id: d.id }, 'Give the canonical decision a three-digit id (D-<NNN>)'),
      ),
    };
  }
  let next = Math.max(0, ...canonical.map((d) => idNumber(d.id))) + 1;
  const ordered = [...local].sort((a, b) => idNumber(a.id) - idNumber(b.id));
  return { map: Object.fromEntries(ordered.map((d) => [d.id, formatPermanentId(next++)])), diagnostics: [] };
}

/** Rewrites whole `D-<n>` tokens that are keys of `map`; every other id stays as it is. */
export const rewriteDecisionRefs = (text: string, map: Readonly<Record<string, string>>): string =>
  text.replace(/\bD-\d+\b/g, (id) => map[id] ?? id);

const decisionBlocks = (text: string): HeadingBlock[] => headingBlocks(text).filter((b) => b.depth === 2 && /^D-\d+:/.test(b.text));

/** Inserts a field bullet after the field bullets that follow a decision heading. */
function insertField(block: string, field: string): string {
  const lines = block.split('\n');
  let at = 1;
  for (let i = 1; i < lines.length && (lines[i]!.trim() === '' || FIELD_LINE.test(lines[i]!)); i++) {
    if (FIELD_LINE.test(lines[i]!)) at = i + 1;
  }
  lines.splice(at, 0, field);
  return lines.join('\n');
}

/** Appends the change's (already rewritten) decisions to the log, with `Change:`, and marks what they supersede (DESIGN §5.3 step 5). */
export function appendDecisions(canonicalText: string | null, localText: string, changeId: string): { text: string | null; diagnostics: Diagnostic[] } {
  const diagnostics: Diagnostic[] = [];
  const added = decisionBlocks(localText).map((b) => {
    const block = localText.slice(b.start, b.end).trim();
    return /^\s*[-*]\s+\*\*Change(?::\*\*|\*\*\s*:)/m.test(block) ? block : insertField(block, `- **Change:** ${changeId}`);
  });
  if (added.length === 0) return { text: canonicalText, diagnostics };
  let text = `${(canonicalText ?? '# Decisions\n').replace(/\n*$/, '')}\n\n${added.join('\n\n')}\n`;
  for (const d of parseDecisions(localText, CANONICAL_FILE).decisions) {
    if (!d.supersedes) continue;
    const target = decisionBlocks(text).find((b) => b.text.startsWith(`${d.supersedes}:`));
    if (!target) continue; // validateChange already reported REF_UNKNOWN_DECISION
    const block = text.slice(target.start, target.end);
    const existing = /^\s*[-*]\s+\*\*Superseded by(?::\*\*|\*\*\s*:)\s*(\S+)/m.exec(block)?.[1];
    if (existing === d.id) continue;
    if (existing) {
      diagnostics.push(diag('error', 'DECISION_ID_CONFLICT', `${d.supersedes} is already superseded by ${existing}`,
        { file: CANONICAL_FILE, id: d.supersedes }, `Supersede ${existing} instead`));
      continue;
    }
    const body = block.trimEnd();
    text = text.slice(0, target.start) + insertField(body, `- **Superseded by:** ${d.id}`) + block.slice(body.length) + text.slice(target.end);
  }
  return { text, diagnostics };
}
```

```ts
import { join } from 'node:path';
import { diag, hasErrors, type Diagnostic } from '../diagnostics.js';
import { parseDecisions } from '../decision/parse.js';
import { appendDecisions, assignPermanentIds, rewriteDecisionRefs } from '../decision/permanent.js';
import type { ChangeSnapshot, LoadedSpec, Project } from '../project/load.js';
import { paths, rel } from '../project/paths.js';
import { parseDelta } from '../spec/parse-delta.js';
import { parseSpec } from '../spec/parse-spec.js';
import { computeStatus } from '../workflow/status.js';
import { applyDelta } from './apply-delta.js';
import { validateChange, validateProject } from './validate-change.js';

export interface ArchiveOptions {
  yes: boolean;
  allowDroppedScenarios: boolean;
  allowBaseDrift: boolean;
}

export interface ArchiveWrite {
  /** Root-relative. Files of the change use their path before the change folder moves. */
  file: string;
  text: string;
}

export interface CapabilitySummary {
  capability: string;
  created: boolean;
  added: string[];
  modified: string[];
  removed: string[];
  sections: string[];
}

export interface ArchivePlan {
  change: string;
  from: string;
  to: string;
  writes: ArchiveWrite[];
  decisions: { local: string; permanent: string }[];
  capabilities: CapabilitySummary[];
}

const blocked = (message: string, fix: string): Diagnostic => diag('error', 'ARCHIVE_BLOCKED', message, undefined, fix);

/** The archive conditions of DESIGN §5.1, one ARCHIVE_BLOCKED per unmet condition. */
export function archiveGates(change: ChangeSnapshot, validation: Diagnostic[], opts: ArchiveOptions): Diagnostic[] {
  const status = computeStatus(change, validation);
  const review = status.artifacts.find((a) => a.id === 'review');
  const out: Diagnostic[] = [];
  if (review?.state === 'stale') out.push(blocked(`the review is stale (${review.detail ?? 'the delta changed'})`, 'Run /comb:review again'));
  if (review?.state === 'missing' && !opts.yes) out.push(blocked('the change has no review', 'Run /comb:review, or pass --yes to archive without one'));
  if (status.questions.open > 0) out.push(blocked(`${status.questions.open} question(s) are still open`, 'Answer or defer them with /comb:clarify'));
  if (!opts.yes && (status.tasks.total === 0 || status.tasks.done < status.tasks.total)) {
    out.push(blocked(`${status.tasks.done}/${status.tasks.total} tasks are done`, 'Finish them, or pass --yes'));
  }
  if (!opts.allowDroppedScenarios && validation.some((d) => d.code === 'SCENARIO_DROPPED')) {
    out.push(blocked('a MODIFIED requirement drops scenarios', 'Restore them, or pass --allow-dropped-scenarios'));
  }
  if (!opts.allowBaseDrift && validation.some((d) => d.code === 'BASE_DRIFT')) {
    out.push(blocked('the spec changed under this change after it was proposed', 'Update the delta to the current spec, then pass --allow-base-drift'));
  }
  return out;
}

/** Everything `comb archive` would write, or the reasons it must not (DESIGN §5.3 steps 1–6). Pure: no file is touched. */
export function planArchive(
  project: Project,
  change: ChangeSnapshot,
  all: ChangeSnapshot[],
  opts: ArchiveOptions,
  today: string,
): { plan: ArchivePlan | null; diagnostics: Diagnostic[] } {
  const validation = [...validateProject(project), ...validateChange(project, change, all)];
  if (hasErrors(validation)) return { plan: null, diagnostics: validation };
  const warnings = validation.filter((d) => d.severity !== 'error');
  const gates = archiveGates(change, validation, opts);
  if (gates.length > 0) return { plan: null, diagnostics: [...gates, ...warnings] };

  const root = project.root;
  const decisionsFile = rel(root, paths.decisions(root));
  const changeFile = (name: 'questions' | 'decisions'): string => rel(root, paths.changeFile(root, change.id, name));
  const local = parseDecisions(change.files.decisions ?? '', changeFile('decisions')).decisions;
  const canonical = parseDecisions(project.decisionsText ?? '', decisionsFile).decisions;
  const ids = assignPermanentIds(local, canonical);
  if (hasErrors(ids.diagnostics)) return { plan: null, diagnostics: ids.diagnostics };
  const rewrite = (text: string): string => rewriteDecisionRefs(text, ids.map);

  const diagnostics: Diagnostic[] = [...warnings];
  const writes: ArchiveWrite[] = [];
  const write = (file: string, before: string | null, text: string): void => {
    if (before !== text) writes.push({ file, text });
  };
  const specs = new Map<string, LoadedSpec>(project.specs);
  const capabilities: CapabilitySummary[] = [];
  for (const d of change.deltas) {
    const deltaText = rewrite(d.text);
    write(d.file, d.text, deltaText);
    const delta = parseDelta(deltaText, d.capability, d.file).delta;
    const base = project.specs.get(d.capability) ?? null;
    const applied = applyDelta(base?.text ?? null, delta, d.file);
    diagnostics.push(...applied.diagnostics);
    const path = paths.spec(root, d.capability);
    const file = rel(root, path);
    write(file, base?.text ?? null, applied.text);
    const parsed = parseSpec(applied.text, d.capability, file);
    specs.set(d.capability, { name: d.capability, path, file, text: applied.text, capability: parsed.capability, diagnostics: parsed.diagnostics });
    capabilities.push({
      capability: d.capability,
      created: base === null,
      added: delta.added.map((r) => r.id),
      modified: delta.modified.map((r) => r.id),
      removed: delta.removed.map((x) => x.id),
      sections: [...delta.modifiedSections, ...delta.addedSections].map((s) => s.heading),
    });
  }
  for (const name of ['questions', 'decisions'] as const) {
    const text = change.files[name];
    if (text !== undefined) write(changeFile(name), text, rewrite(text));
  }
  const log = appendDecisions(project.decisionsText, rewrite(change.files.decisions ?? ''), change.id);
  diagnostics.push(...log.diagnostics);
  if (log.text !== null) write(decisionsFile, project.decisionsText, log.text);

  // DESIGN §5.3 step 6: the merged canonical files must still validate.
  diagnostics.push(...validateProject({ ...project, specs, decisionsText: log.text }).filter((d) => d.severity === 'error'));
  if (hasErrors(diagnostics)) return { plan: null, diagnostics };
  return {
    plan: {
      change: change.id,
      from: rel(root, change.dir),
      to: rel(root, join(paths.archiveDir(root), `${today}-${change.id}`)),
      writes,
      decisions: Object.entries(ids.map).map(([l, p]) => ({ local: l, permanent: p })),
      capabilities,
    },
    diagnostics,
  };
}
```

```ts
/** Re-applies the BOM and CRLF line endings of `raw` (the file on disk) to LF-normalized `text`. */
export function restoreTextStyle(raw: string, text: string): string {
  const lines = raw.includes('\r\n') ? text.replace(/\n/g, '\r\n') : text;
  return raw.startsWith('\uFEFF') ? `\uFEFF${lines}` : lines;
}
```

```ts
import { existsSync, mkdirSync, readFileSync, renameSync, rmSync, writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { diag, type Diagnostic } from '../diagnostics.js';
import { restoreTextStyle } from '../markdown/text.js';
import type { ArchivePlan } from './archive-plan.js';

const TMP = '.comb-tmp';

/**
 * DESIGN §5.3 step 7: write every file to a temp file, move the change folder into the archive,
 * then rename the temp files into place. If anything fails before the move, the canonical files are untouched.
 */
export function executeArchive(root: string, plan: ArchivePlan): Diagnostic[] {
  const abs = (file: string): string => join(root, file);
  if (existsSync(abs(plan.to))) {
    return [diag('error', 'ARCHIVE_TARGET_EXISTS', `${plan.to} already exists`, { file: plan.to }, 'Move or remove that folder, then archive again')];
  }
  const temps: string[] = [];
  try {
    for (const w of plan.writes) {
      const target = abs(w.file);
      const raw = existsSync(target) ? readFileSync(target, 'utf8') : null;
      mkdirSync(dirname(target), { recursive: true });
      writeFileSync(`${target}${TMP}`, raw === null ? w.text : restoreTextStyle(raw, w.text));
      temps.push(`${target}${TMP}`);
    }
    mkdirSync(dirname(abs(plan.to)), { recursive: true });
    renameSync(abs(plan.from), abs(plan.to));
  } catch (e) {
    for (const t of temps) rmSync(t, { force: true });
    throw e;
  }
  const moved = (file: string): string => (file.startsWith(`${plan.from}/`) ? `${plan.to}${file.slice(plan.from.length)}` : file);
  for (const w of plan.writes) renameSync(`${abs(moved(w.file))}${TMP}`, abs(moved(w.file)));
  return [];
}
```

```ts
import { executeArchive } from '../../core/change/archive-execute.js';
import { planArchive, type ArchivePlan, type CapabilitySummary } from '../../core/change/archive-plan.js';
import { loadAllChanges, loadProject } from '../../core/project/load.js';

export interface ArchiveSummary {
  change: string;
  archivedTo: string;
  decisions: { local: string; permanent: string }[];
  capabilities: CapabilitySummary[];
  files: string[];
}

const summarize = (plan: ArchivePlan): ArchiveSummary => ({
  change: plan.change,
  archivedTo: plan.to,
  decisions: plan.decisions,
  capabilities: plan.capabilities,
  files: plan.writes.map((w) => (w.file.startsWith(`${plan.from}/`) ? `${plan.to}${w.file.slice(plan.from.length)}` : w.file)),
});

const human = (id: string) => (d: ArchiveSummary | null): string => {
  if (!d) return `not archived: ${id}`;
  const caps = d.capabilities.map((c) => {
    const parts = [...c.added.map((x) => `+${x}`), ...c.modified.map((x) => `~${x}`), ...c.removed.map((x) => `-${x}`), ...c.sections.map((s) => `§${s}`)];
    return `${c.capability}${c.created ? ' (new)' : ''}: ${parts.join(' ')}`;
  });
  const decisions = d.decisions.length > 0 ? [`decisions: ${d.decisions.map((x) => `${x.local} → ${x.permanent}`).join(', ')}`] : [];
  return [`archived ${d.change} → ${d.archivedTo}`, ...caps, ...decisions].join('\n');
};

export function registerArchive(program: Command, ctx: CliContext): void {
  program
    .command('archive <id>')
    .description('merge a change into the specs and the decision log, then move it to changes/archive')
    .option('--yes', 'archive with unfinished tasks or without a review')
    .option('--allow-dropped-scenarios', 'accept MODIFIED requirements that drop scenarios')
    .option('--allow-base-drift', 'accept requirements that changed in the spec after the proposal')
    .option('--json', 'JSON output')
    .action((id: string, opts: { yes?: boolean; allowDroppedScenarios?: boolean; allowBaseDrift?: boolean; json?: boolean }) => {
      const json = opts.json === true;
      const root = requireRoot(ctx, 'archive', json);
      if (!root) return;
      const all = loadAllChanges(root);
      const change = all.find((c) => c.id === id);
      if (!change) {
        usageError(ctx, 'archive', json, 'CHANGE_NOT_FOUND', `change "${id}" not found`, 'Archived changes are in comb/changes/archive/');
        return;
      }
      const options = { yes: opts.yes === true, allowDroppedScenarios: opts.allowDroppedScenarios === true, allowBaseDrift: opts.allowBaseDrift === true };
      const { plan, diagnostics } = planArchive(loadProject(root), change, all, options, ctx.today());
      if (!plan) {
        finish(ctx, envelope<ArchiveSummary | null>('archive', null, diagnostics), json, human(id));
        return;
      }
      const failed = executeArchive(root, plan);
      finish(ctx, envelope<ArchiveSummary | null>('archive', failed.length > 0 ? null : summarize(plan), [...diagnostics, ...failed]), json, human(id));
    });
}
```

```ts
import { parseDecisions } from '../decision/parse.js';
import { headingBlocks } from '../markdown/blocks.js';
import type { ChangeStatus } from '../workflow/status.js';
import type { ChangeSnapshot, Project } from './load.js';
import { paths, rel, type ChangeFileName } from './paths.js';

export interface ListData {
  specs: { capability: string; prefix: string | null; file: string; requirements: { id: string; title: string }[] }[];
  decisions: { id: string; title: string; supersededBy: string | null }[];
  changes: string[];
  archived: string[];
}

export type ShowData =
  | { kind: 'requirement'; id: string; capability: string; file: string; line: number; title: string; text: string; pendingChanges: string[] }
  | { kind: 'decision'; id: string; file: string; line: number; title: string; text: string; supersededBy: string | null }
  | { kind: 'change'; id: string; files: string[]; status: ChangeStatus };

export function listProject(project: Project, changes: ChangeSnapshot[], archived: string[]): ListData {
  return {
    specs: [...project.specs.values()].map((s) => ({
      capability: s.name,
      prefix: s.capability.prefix,
      file: s.file,
      requirements: s.capability.requirements.map((r) => ({ id: r.id, title: r.title })),
    })),
    decisions: parseDecisions(project.decisionsText ?? '', 'comb/decisions.md').decisions.map((d) => ({ id: d.id, title: d.title, supersededBy: d.supersededBy })),
    changes: changes.map((c) => c.id),
    archived,
  };
}

/** A canonical requirement (REQ-…), a canonical decision (D-NNN) or an active change, by id. */
export function showItem(project: Project, changes: ChangeSnapshot[], key: string, statusOf: (c: ChangeSnapshot) => ChangeStatus): ShowData | null {
  for (const s of project.specs.values()) {
    const r = s.capability.requirements.find((x) => x.id === key);
    if (!r) continue;
    const pendingChanges = changes
      .filter((c) => c.deltas.some((d) => [...d.delta.modified.map((m) => m.id), ...d.delta.removed.map((x) => x.id)].includes(key)))
      .map((c) => c.id);
    return { kind: 'requirement', id: r.id, capability: s.name, file: s.file, line: r.line, title: r.title, text: r.block.trim(), pendingChanges };
  }
  const log = project.decisionsText ?? '';
  const d = parseDecisions(log, 'comb/decisions.md').decisions.find((x) => x.id === key);
  if (d) {
    const block = headingBlocks(log).find((b) => b.depth === 2 && b.line === d.line);
    const text = block ? log.slice(block.start, block.end).trim() : '';
    return { kind: 'decision', id: d.id, file: rel(project.root, paths.decisions(project.root)), line: d.line, title: d.title, text, supersededBy: d.supersededBy };
  }
  const c = changes.find((x) => x.id === key);
  if (!c) return null;
  const files = [
    ...(Object.keys(c.files) as ChangeFileName[]).map((n) => rel(project.root, paths.changeFile(project.root, c.id, n))),
    ...c.deltas.map((x) => x.file),
  ].sort();
  return { kind: 'change', id: c.id, files, status: statusOf(c) };
}
```

```ts
import type { Command } from 'commander';
```

```ts
import { describeStatus } from './status.js';

const human = (d: ShowData): string => {
  if (d.kind === 'change') return [d.id, ...d.files.map((f) => `  ${f}`), describeStatus(d.status)].join('\n');
  const notes = [
    `${d.file}:${d.line}`,
    ...(d.kind === 'requirement' && d.pendingChanges.length > 0 ? [`changed by ${d.pendingChanges.join(', ')}`] : []),
    ...(d.kind === 'decision' && d.supersededBy ? [`superseded by ${d.supersededBy}`] : []),
  ];

export function registerShow(program: Command, ctx: CliContext): void {

    .command('show <id>')
    .description('show a requirement (REQ-…), a decision (D-NNN) or a change by id')

      const json = opts.json === true;
      const root = requireRoot(ctx, 'show', json);
      if (!root) return;

      const all = loadAllChanges(root);
      const item = showItem(project, all, key, (c) => computeStatus(c, validateChange(project, c, all)));

        return;
      }
      finish(ctx, envelope('show', item, []), json, human);
    });
}
```
