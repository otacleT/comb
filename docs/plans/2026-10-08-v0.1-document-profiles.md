# v0.1 Document Profiles (solo) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/comb:docs` writes six readable product documents as a projection of the canonical specs, decisions and open questions, and `comb docs` holds them to it: every statement cited, every requirement covered, nothing stale (V0_SCOPE experience E7).

**Architecture:**
- A document profile is a declarative folder: `profile.yaml`, `SKILL.md` and `templates/`. The built-in `solo` profile lives in `templates/profiles/solo/`. `src/core/docs/` loads a profile, hashes each output's declared sources, extracts and checks citations, and computes a status per output (`missing`, `stale`, `done` or `user-owned`).
- The agent writes the documents through the `docs` skill, guided by `comb instructions docs`. It never writes hashes: `comb docs stamp` records the source hash in a freshly written document's first line. `comb docs` reports the state of every output and every diagnostic.

**Tech Stack:** Node ≥22.12, TypeScript 7 (strict, NodeNext), commander 15, yaml 2, mdast-util-from-markdown, vitest 5.

**Spec:** `docs/specs/2026-10-08-document-profiles-design.md` (binding), plus `docs/DESIGN.md` §3.9, §7, §9.1 and `docs/PRODUCT_PRINCIPLES.md` principle 10.

## Global Constraints

- Everything in the M1–M4 plans' Global Constraints still applies.
- Documents are projections of the canonical files (`comb/specs/`, `comb/decisions.md`, `comb/changes/archive/*/questions.md`) and of `config.context`. Active changes are never a source.
- The CLI never writes document bodies. It writes only the stamped first line, and only on documents whose first line is the bare marker `<!-- generated by comb -->`.
- Exact formats:
  - bare marker: `<!-- generated by comb -->`
  - stamped header: `<!-- generated by comb from sha256:<16 hex>; edit the specs, not this file -->`
  - citations: `REQ-<PREFIX>-<NNN>`, `D-<NNN>` (three or more digits), `<change-id>#Q-<n>` (the archive folder name without its `YYYY-MM-DD-` date), and `config:context`
  - the gaps heading: `## Gaps` (English in every language)
- Output path: `<documents.dir>/<output.path>`, root-relative with forward slashes. `documents.dir` defaults to `docs` and `documents.profile` to `solo`, the only profile in v0.1.
- New diagnostic codes (DESIGN §7.2):
  - `DOC_MISSING`, `DOC_STALE`, `DOC_USER_OWNED` (errors, exit 1)
  - `DOC_UNCITED_SECTION`, `DOC_UNCOVERED` (warnings)
  - `REF_UNKNOWN_REQ`, `REF_UNKNOWN_DECISION` and `REF_UNKNOWN_QUESTION` are reused.
- Real-LLM runs: about $5–10, all in Task 7.
- Work on branch `feat/v0.1-docs`. The spec commits come before this plan's commit.

## Review Focus

1. **A project that already has its own `docs/` folder.** Hand-written files at output paths are reported as `user-owned`: never stamped, never overwritten, and the agent is told to ask. Files that are not outputs, such as `docs/README.md`, are never touched. Pinned in Task 4.
2. **Running `comb docs stamp` after the sources changed but without regenerating** must not turn a stale document into a done one. Pinned in Task 4.
3. **Citations of requirements that exist only in an active, unarchived change** are errors, because documents reflect the canonical specs only. Pinned in Task 3.
4. **A document that has only `## Gaps`** (for example screens.md when no screen is specified) is valid: no uncited-section warning. Pinned in Task 3.
5. **Archived change folders whose change id starts with digits** (`2026-10-08-2fa-login`) must resolve to `2fa-login` for `<change-id>#Q-<n>` citations. Pinned in Task 2.

Create `src/core/docs/profile.ts`:

```ts
import { existsSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import { parse as parseYaml } from 'yaml';
import { diag, type Diagnostic } from '../diagnostics.js';
import { normalizeText } from '../markdown/text.js';

export const DOC_SOURCES = ['config', 'specs', 'decisions', 'open-questions'] as const;
export type DocSource = (typeof DOC_SOURCES)[number];

export interface DocOutput {
  id: string;
  /** Relative to `documents.dir`. */
  path: string;
  /** The template text. */
  template: string;
  audience: string;
  sources: DocSource[];
}

export interface Profile {
  id: string;
  dir: string;
  /** The writing discipline (SKILL.md), handed to the agent by `comb instructions docs`. */
  skill: string;
  outputs: DocOutput[];
}

/** Reads a document profile folder: profile.yaml, SKILL.md and the templates its outputs name. */
export function loadProfile(dir: string): { profile: Profile | null; diagnostics: Diagnostic[] } {
  const bad = (message: string): { profile: null; diagnostics: Diagnostic[] } => ({
    profile: null,
    diagnostics: [diag('error', 'CONFIG_INVALID', `document profile ${dir}: ${message}`)],
  });
  const file = join(dir, 'profile.yaml');
  if (!existsSync(file)) return bad('profile.yaml not found');
  let raw: unknown;
  try {
    raw = parseYaml(readFileSync(file, 'utf8'));
  } catch (e) {
    return bad(`invalid YAML: ${(e as Error).message}`);
  }
  const r = (raw ?? {}) as Record<string, unknown>;
  if (r.type !== 'comb.document-profile') return bad('"type" must be comb.document-profile');
  if (r.version !== 1) return bad('"version" must be 1');
  if (typeof r.id !== 'string' || !Array.isArray(r.outputs) || r.outputs.length === 0) return bad('"id" and a non-empty "outputs" list are required');
  const skillFile = join(dir, 'SKILL.md');
  if (!existsSync(skillFile)) return bad('SKILL.md not found');
  const outputs: DocOutput[] = [];
  for (const item of r.outputs as unknown[]) {
    const o = (item ?? {}) as Record<string, unknown>;
    if (typeof o.id !== 'string' || typeof o.path !== 'string' || typeof o.template !== 'string' || typeof o.audience !== 'string') {
      return bad('every output needs "id", "path", "template" and "audience"');
    }
    const sources = Array.isArray(o.sources) ? (o.sources as unknown[]) : [];
    if (sources.length === 0 || sources.some((s) => !(DOC_SOURCES as readonly unknown[]).includes(s))) {
      return bad(`output ${o.id}: "sources" must be a non-empty list of ${DOC_SOURCES.join(', ')}`);
    }
    const templateFile = join(dir, o.template);
    if (!existsSync(templateFile)) return bad(`output ${o.id}: template ${o.template} not found`);
    outputs.push({ id: o.id, path: o.path, template: normalizeText(readFileSync(templateFile, 'utf8')), audience: o.audience, sources: sources as DocSource[] });
  }
  return { profile: { id: r.id, dir, skill: normalizeText(readFileSync(skillFile, 'utf8')), outputs }, diagnostics: [] };
}
```

Create `templates/profiles/solo/SKILL.md`:

```markdown
# Writing the solo product docs

These documents are a readable projection of the canonical specs (comb/specs/), the decision log (comb/decisions.md) and the open questions of archived changes. They are for a solo developer and their collaborators: how the product behaves, all in one place, easier to read than spec.md.

1. Every statement about behavior cites where it comes from, in parentheses at the end of the sentence or bullet:
   - a requirement: REQ-<PREFIX>-<NNN>
   - a decision: D-<NNN>
   - an open question: <change-id>#Q-<n> (the change id is the archive folder name without its date)
   - the project context: config:context
2. Never write anything the sources do not say. When the template asks for something the sources do not cover (for example, no screen is described), list it under "## Gaps" at the end of that document, one bullet per missing piece, naming the requirement it would belong to when there is one. Gaps are the input for the next /comb:propose.
3. Do not copy requirements. Reorganize them for the reader (by feature, by screen, by flow), summarize each rule in a sentence, and cite it.
4. Keep it short: a reader gets the picture of a document in a few minutes. Prefer lists and small tables to long prose.
5. Write headings and prose in the project language, except the heading "## Gaps", which stays in English.
6. The first line of every document you write is exactly <!-- generated by comb -->. Never overwrite a file whose first line is not a generated-by-comb marker: it belongs to the user.
```

```ts
export interface ArchivedQuestions {
  /** The change id: the archive folder name without its YYYY-MM-DD- date. */
  change: string;
  folder: string;
  file: string;
  text: string;
}

/** questions.md of every archived change (the source of the open-questions document). */
export function loadArchivedQuestions(root: string): ArchivedQuestions[] {
  return listArchivedIds(root).flatMap((folder) => {
    const p = join(paths.archiveDir(root), folder, 'questions.md');
```

```ts
export const DOC_MARKER = '<!-- generated by comb';
const STAMPED_RE = /^<!-- generated by comb from (sha256:[0-9a-f]{16})/;

const firstLine = (text: string): string => {
  const nl = text.indexOf('\n');
  return nl < 0 ? text : text.slice(0, nl);
};

/** A generated document starts with the marker; a stamped one also records the source hash it was generated from. */
export function docHeader(text: string): { generated: boolean; hash: string | null } {
  const first = firstLine(text);
  if (!first.startsWith(DOC_MARKER)) return { generated: false, hash: null };
  return { generated: true, hash: STAMPED_RE.exec(first)?.[1] ?? null };
}

export const stampedHeader = (hash: string): string => `<!-- generated by comb from ${hash}; edit the specs, not this file -->`;

/** Replaces the first line (the marker) with the stamped header. */
export function stampDoc(text: string, hash: string): string {
  const nl = text.indexOf('\n');
  return `${stampedHeader(hash)}${nl < 0 ? '\n' : text.slice(nl)}`;
}
```

```ts
export function docInputs(project: Project, questions: ArchivedQuestions[]): DocInputs {

const byFile = <T extends { file: string }>(xs: readonly T[]): T[] => [...xs].sort((a, b) => (a.file < b.file ? -1 : a.file > b.file ? 1 : 0));

/** The root-relative files an output reads (config means comb/config.yaml). */
export function sourceFiles(sources: readonly DocSource[], inputs: DocInputs): string[] {
  const files = sources.flatMap((s) => {
    if (s === 'config') return ['comb/config.yaml'];
    if (s === 'specs') return byFile(inputs.specs).map((f) => f.file);
    if (s === 'decisions') return inputs.decisions ? [inputs.decisions.file] : [];
    return byFile(inputs.questions).map((f) => f.file);
  });
  return [...new Set(files)];
}

/** Hash of the declared sources only, so an output goes stale exactly when what it is built from changes. */
export function sourceHash(sources: readonly DocSource[], inputs: DocInputs): string {
  const parts: string[] = [];
  for (const s of [...new Set(sources)].sort()) {
    if (s === 'config') parts.push(`config:context\n${inputs.context}`);
    if (s === 'specs') for (const f of byFile(inputs.specs)) parts.push(`${f.file}\n${f.text}`);
    if (s === 'decisions') parts.push(`comb/decisions.md\n${inputs.decisions?.text ?? ''}`);
    if (s === 'open-questions') for (const f of byFile(inputs.questions)) parts.push(`${f.file}\n${f.text}`);
  }
  return `sha256:${createHash('sha256').update(parts.join('\n\n')).digest('hex').slice(0, 16)}`;
}

/** The ids documents may cite: canonical requirements (and retired ones, to name them), decisions and archived questions. */
export function docRefs(project: Project, questions: ArchivedQuestions[]): DocRefs {
  const capabilities = [...project.specs.values()].map((s) => s.capability);
  const byChange = new Map<string, Set<string>>();
  for (const q of questions) {
    const ids = byChange.get(q.change) ?? new Set<string>();
    for (const x of parseQuestions(q.text, q.file).questions) ids.add(x.id);
    byChange.set(q.change, ids);
  }
  return {
    requirements: new Set(capabilities.flatMap((c) => c.requirements.map((r) => r.id))),
    retired: new Set(capabilities.flatMap((c) => c.retired)),
    decisions: new Set(parseDecisions(project.decisionsText ?? '', 'comb/decisions.md').decisions.map((d) => d.id)),
    questions: byChange,
  };
}
```

```ts
import { diag, type Diagnostic } from '../diagnostics.js';
import { headingBlocks } from '../markdown/blocks.js';

export interface DocRefs {
  requirements: ReadonlySet<string>;
  retired: ReadonlySet<string>;
  decisions: ReadonlySet<string>;
  /** Change id → the question ids of its archived questions.md. */
  questions: ReadonlyMap<string, ReadonlySet<string>>;
}

export interface Citations {
  requirements: string[];
  decisions: string[];
  questions: { change: string; id: string }[];
  context: boolean;
}

const REQ_RE = /\bREQ-[A-Z][A-Z0-9]*-\d{3,}\b/g;
const DECISION_RE = /\bD-\d{3,}\b/g;
const QUESTION_RE = /\b([a-z0-9]+(?:-[a-z0-9]+)*)#(Q-\d+)\b/g;
const CONTEXT = 'config:context';

export function extractCitations(text: string): Citations {
  const questions = new Map<string, { change: string; id: string }>();
  for (const m of text.matchAll(QUESTION_RE)) questions.set(`${m[1]}#${m[2]}`, { change: m[1]!, id: m[2]! });
  return {
    requirements: [...new Set(text.match(REQ_RE) ?? [])],
    decisions: [...new Set(text.match(DECISION_RE) ?? [])],
    questions: [...questions.values()],
    context: text.includes(CONTEXT),
  };
}

const citesAnything = (c: Citations): boolean => c.requirements.length + c.decisions.length + c.questions.length > 0 || c.context;

/** Every cited id must exist in the canonical sources (documents reflect archived content only). */
export function checkCitations(text: string, file: string, refs: DocRefs): Diagnostic[] {
  const c = extractCitations(text);
  const fix = 'Run /comb:docs to rewrite it from the current specs';
  return [
    ...c.requirements
      .filter((id) => !refs.requirements.has(id))
      .map((id) => diag('error', 'REF_UNKNOWN_REQ', refs.retired.has(id) ? `${id} was removed from the specs` : `${id} is not in the specs`, { file, id }, fix)),
    ...c.decisions.filter((id) => !refs.decisions.has(id)).map((id) => diag('error', 'REF_UNKNOWN_DECISION', `${id} is not in comb/decisions.md`, { file, id }, fix)),
    ...c.questions
      .filter((q) => !refs.questions.get(q.change)?.has(q.id))
      .map((q) => diag('error', 'REF_UNKNOWN_QUESTION', `${q.change}#${q.id} is not a question of an archived change`, { file, id: `${q.change}#${q.id}` }, fix)),
  ];
}

/** `##` and `###` sections without any citation, except "## Gaps" and everything under it. */
export function uncitedSections(text: string, file: string): Diagnostic[] {
  const blocks = headingBlocks(text).filter((b) => b.depth === 2 || b.depth === 3);
  const gaps = blocks.filter((b) => b.depth === 2 && b.text === 'Gaps');
  return blocks
    .filter((b) => !gaps.some((g) => b.start >= g.start && b.start < g.end))
    .filter((b) => !citesAnything(extractCitations(text.slice(b.contentStart, b.end))))
    .map((b) => diag('warning', 'DOC_UNCITED_SECTION', `"${b.text}" cites nothing`, { file, line: b.line }, 'Cite the requirements or decisions it comes from, or move it under ## Gaps'));
}
```

```ts
import { diag, type Diagnostic } from '../diagnostics.js';
import { checkCitations, extractCitations, uncitedSections, type DocRefs } from './citations.js';
import { docHeader } from './header.js';
import type { Profile } from './profile.js';
import { sourceHash, type DocInputs } from './sources.js';

export type DocState = 'missing' | 'stale' | 'done' | 'user-owned';

export interface DocOutputStatus {
  id: string;
  /** Root-relative: `<documents.dir>/<output path>`. */
  path: string;
  state: DocState;
  sourceHash: string;
  recordedHash: string | null;
}

export interface DocsStatus {
  profile: string;
  dir: string;
  outputs: DocOutputStatus[];
  /** Canonical requirements that no generated document cites. */
  uncovered: string[];
}

export function docsStatus(
  profile: Profile,
  dir: string,
  inputs: DocInputs,
  refs: DocRefs,
  texts: ReadonlyMap<string, string | null>,
): { status: DocsStatus; diagnostics: Diagnostic[] } {
  const diagnostics: Diagnostic[] = [];
  const cited = new Set<string>();
  const outputs = profile.outputs.map((o): DocOutputStatus => {
    const path = `${dir}/${o.path}`;
    const hash = sourceHash(o.sources, inputs);
    const text = texts.get(path) ?? null;
    if (text === null) {
      diagnostics.push(diag('error', 'DOC_MISSING', `${path} has not been generated`, { file: path }, 'Run /comb:docs'));
      return { id: o.id, path, state: 'missing', sourceHash: hash, recordedHash: null };
    }
    const header = docHeader(text);
    if (!header.generated) {
      diagnostics.push(diag('error', 'DOC_USER_OWNED', `${path} exists but was not generated by comb`, { file: path, line: 1 },
        'Move it away, or set documents.dir in comb/config.yaml to another folder'));
      return { id: o.id, path, state: 'user-owned', sourceHash: hash, recordedHash: null };
    }
    diagnostics.push(...checkCitations(text, path, refs), ...uncitedSections(text, path));
    for (const id of extractCitations(text).requirements) cited.add(id);
    if (header.hash !== hash) {
      diagnostics.push(header.hash === null
        ? diag('error', 'DOC_STALE', `${path} is not stamped yet`, { file: path, line: 1 }, 'Run comb docs stamp')
        : diag('error', 'DOC_STALE', `${path} was generated from older sources`, { file: path, line: 1 }, 'Run /comb:docs'));
      return { id: o.id, path, state: 'stale', sourceHash: hash, recordedHash: header.hash };
    }
    return { id: o.id, path, state: 'done', sourceHash: hash, recordedHash: header.hash };
  });
  const uncovered = [...refs.requirements].filter((id) => !cited.has(id)).sort();
  if (uncovered.length > 0 && outputs.some((o) => o.state === 'done' || o.state === 'stale')) {
    diagnostics.push(diag('warning', 'DOC_UNCOVERED', `no document cites ${uncovered.join(', ')}`, undefined, 'Cover them in features.md, screens.md or flows.md'));
  }
  return { status: { profile: profile.id, dir, outputs, uncovered }, diagnostics };
}
```

```ts
  project: Project;
  profile: Profile;
  inputs: DocInputs;
  status: DocsStatus;
  diagnostics: Diagnostic[];
}

/** The project, its document profile and the state of every output (shared by `comb docs` and `comb instructions docs`). */
export function loadDocs(root: string, templatesDir: string): { context: DocsContext | null; diagnostics: Diagnostic[] } {
  const project = loadProject(root);
  if (hasErrors(project.diagnostics)) return { context: null, diagnostics: project.diagnostics };
  const loaded = loadProfile(join(templatesDir, 'profiles', project.config.documents.profile));
  if (!loaded.profile) return { context: null, diagnostics: loaded.diagnostics };
  const questions = loadArchivedQuestions(root);
  const inputs = docInputs(project, questions);
  const dir = project.config.documents.dir;
  const texts = new Map(loaded.profile.outputs.map((o) => [`${dir}/${o.path}`, readIfExists(join(root, dir, o.path))] as const));
  const { status, diagnostics } = docsStatus(loaded.profile, dir, inputs, docRefs(project, questions), texts);
  return { context: { project, profile: loaded.profile, inputs, status, diagnostics }, diagnostics };
}
```

```ts
import type { CliContext } from '../app.js';

interface StampResult {
  stamped: string[];
  skipped: { path: string; reason: string }[];
}

const describeDocs = (s: DocsStatus): string =>
  [
    `docs (${s.profile}) in ${s.dir}/`,
    ...s.outputs.map((o) => `  ${o.path.padEnd(32)}${o.state}`),
    ...(s.uncovered.length > 0 ? [`not cited by any document: ${s.uncovered.join(', ')}`] : []),
  ].join('\n');

const describeStamp = (r: StampResult): string =>
  [...r.stamped.map((p) => `stamped  ${p}`), ...r.skipped.map((s) => `skipped  ${s.path} (${s.reason})`)].join('\n');

/** Records the source hash on documents the agent just wrote (bare marker, no hash). Stale, user-owned and missing ones are left alone. */
function stamp(root: string, docs: DocsContext): StampResult {
  const result: StampResult = { stamped: [], skipped: [] };
  for (const o of docs.status.outputs) {
    const file = join(root, o.path);
    if (!existsSync(file)) {
      result.skipped.push({ path: o.path, reason: 'missing' });
      continue;
    }
    const raw = readFileSync(file, 'utf8');
    const header = docHeader(normalizeText(raw));
    if (!header.generated) {
      result.skipped.push({ path: o.path, reason: 'user-owned' });
      continue;
    }
    if (header.hash !== null) {
      result.skipped.push({ path: o.path, reason: header.hash === o.sourceHash ? 'already stamped' : 'stale: rewrite it with /comb:docs first' });
      continue;
    }
    writeFileSync(file, restoreTextStyle(raw, stampDoc(normalizeText(raw), o.sourceHash)));
    result.stamped.push(o.path);
  }
  return result;
}

export function registerDocs(program: Command, ctx: CliContext): void {
  program
    .command('docs [action]')
    .description('check the generated product docs; "comb docs stamp" records the sources of freshly written ones')
    .option('--json', 'JSON output')
    .action((action: string | undefined, opts: { json?: boolean }) => {
      const json = opts.json === true;
      if (action !== undefined && action !== 'stamp') {
        usageError(ctx, 'docs', json, 'USAGE_ERROR', `unknown action "${action}"`, 'Use "comb docs" or "comb docs stamp"');
        return;
      }
      const root = requireRoot(ctx, 'docs', json);
      if (!root) return;
      const { context, diagnostics } = loadDocs(root, TEMPLATES_DIR);
      if (!context) {
        finish(ctx, envelope('docs', null, diagnostics), json, () => '');
        return;
      }
      if (action === 'stamp') {
        finish(ctx, envelope('docs', stamp(root, context), []), json, describeStamp);
        return;
      }
      finish(ctx, envelope('docs', context.status, context.diagnostics), json, describeDocs);
    });
}
```
